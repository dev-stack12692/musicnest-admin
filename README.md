# MusicNest Admin Panel

Web admin panel for MusicNest public playlists. Hosted on GitHub Pages.

- Sign in with the admin Google account only.
- Create/edit/delete/publish playlists; published playlists appear in the MusicNest app for all users (Firestore `admin_playlists` collection).
- Firestore security rules enforce that only the admin account can write.

Live: https://dev-stack12692.github.io/musicnest-admin/
